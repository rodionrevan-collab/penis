# DEV MODE

Локальный режим разработчика для тестирования игры без ручного прохождения.

## Вход

Нажмите **Ctrl+Shift+D** во время запуска игры.

Состояние режима хранится локально в:

`user://developer_mode.txt`

Это не меняет правила обычной игры для других сохранений и не является частью обычной прогрессии.

## Возможности

- открыть все 100 уровней острова 1;
- отметить весь остров 1 пройденным и получить 3★ на всех уровнях;
- получить 100 дополнительных звёзд и по 99 каждого бустера;
- сразу перейти к выбранному уровню;
- сбросить прогресс;
- открыть предпросмотр острова 2 «Коралловые руины».

## Важно

Предпросмотр острова 2 пока показывает его контент, уровни и новые механики, но не запускает отдельную полноценную кампанию. Игровая логика второго острова подключается после стабилизации острова 1.
